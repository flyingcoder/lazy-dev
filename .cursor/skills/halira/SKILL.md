# HALIRA Protocol

**When to use this skill:** Task involves foundational contradictions, paradigm shift, irreducible paradoxes, or architecture-level paradoxes. Use when Mode 2 is triggered or when applying the full 7-step HALIRA sequence.

**Description:** Full HALIRA Protocol: 7 steps (Potentia→Seed, Boundary→Axis, Recursion→Meta, Integration→Weave, Anomaly→Non, Rupture→Para∘Ortho, Recognition→Bind), step→operator mapping with λ and trajectory, Meta/Non constraint (never Non after Meta), anomaly detection and rupture navigation, decision tree for Step 5 when Meta was used.

---

## 7-Step Sequence

1. **Potentia (Seed λ=0.28):** Frame as potential; identify tensions; don't jump to solutions. ∅ → S*
2. **Boundary (Axis λ=0.31):** Define components, constraints, relationships. S* → S*
3. **Recursion (Meta λ=0.80):** Self-reference; model the model. **Max 2 consecutive Meta.** S* → S*
4. **Integration (Weave λ=0.33):** Weave perspectives; hold competing models; generate "perfect" solution in paradigm. S* → J=0
5. **Anomaly (Non λ=0.90):** Attack your design; find irreducible flaw. **FORBIDDEN after Meta.** J=0 → S*
6. **Rupture (Para ∘ Ortho λ_eff=0.48):** First try Ortho (duality); if fails, Para (paradigm shift). S* → S*
7. **Recognition (Bind λ=0.38):** Present as new invariant. S* → S*

**Full sequence:** Seed ∘ Axis ∘ Meta ∘ Weave ∘ Non ∘ Para ∘ Ortho ∘ Bind (λ_eff ≈ 0.52)

## Critical Constraints
- **DO NOT SKIP Step 5** (Anomaly Detection).
- **Never Non after Meta.** If Meta was used in Step 3: use Para or Retro for anomaly detection in Step 5, not Non.

## Step 5 when Meta was used
- Option A: Skip Step 5 (only if anomaly obvious from Step 4)
- Option B: Use **Para** for anomaly detection (recommended)
- Option C: Use **Retro** for backward anomaly detection
- NEVER use Non after Meta.

## Rupture Navigation
If anomaly found: first try Ortho (opposite perspective); if that fails, apply Para (paradigm shift). Don't patch—transcend.
