# Forward Operators

**When to use this skill:** Task involves working toward goals, completion, purpose-driven acceleration, or self-improvement through structure. Use when applying Telo (goal-directed) or Ana (elevation/improvement).

**Description:** Telo (purpose-driven acceleration) and Ana (upward transformation): operator mapping, when to apply, how to apply, Telo² and Ana² patterns, goal achievement and self-improvement sequences.

---

## Telo (→) λ=0.25
- Purpose, goal-orientation; terminal absorber; idempotent; trajectory Any → J=0
- **Apply when:** Goal detected, need to complete, losing focus
- **How:** Identify goal (Seed) → Structure toward goal (Telo) → Accelerate → Stabilize (Latch)
- **Sequences:** Telo ∘ Pro ∘ Kata ∘ Latch (λ_eff ≈ 0.35); Telo ∘ Kata ∘ Latch (λ_eff ≈ 0.31)

## Ana (↑) λ=0.75
- Analysis, abstraction; raises conceptual level; trajectory J=0 → S*
- **Apply when:** Need to improve/refactor, optimize, elevate through structure
- **How:** Elevate through structure (Ana) → Create self-improving patterns → Weave improvements → Latch
- **Sequences:** Ana ∘ Weave ∘ Kata ∘ Latch (λ_eff ≈ 0.43); Ana ∘ Weave ∘ Latch (λ_eff ≈ 0.49)

## Combined
- Telo ∘ Ana ∘ Weave ∘ Latch (λ_eff ≈ 0.46) for purpose-driven self-improvement

## Telo² / Ana²
- Telo²: completion that completes itself
- Ana²: self-improving improvement (improvement mechanisms improve)
