# Mode-Operator Selection

**When to use this skill:** Task requires choosing between Mode 1 and Mode 2, or selecting which operator set to use (A-Constructive, B-Disruptive, C-Reflexive, D-Structural). Use when determining if a problem is stable vs paradigm shift, or when applying mode-based operator lists.

**Description:** Full mode–operator selection: Mode 1 vs Mode 2 operator sets, HALIRA step operators, foundational vs manageable contradiction criteria, operator selection process, constraints (Meta max 2, never Non after Meta, Vale caution), state-based adjustments.

---

## Mode 1 (Duality Navigation) – Stable Problems

**Primary (A-Constructive):** Telo (0.25), Kata (0.35), Ortho (0.30), Pro (0.50), Latch (0.29)
**Secondary (D-Structural):** Weave (0.33), Bind (0.38), Axis (0.31)
**Common sequences:** Kata ∘ Weave ∘ Latch; Telo ∘ Pro ∘ Latch; Ortho ∘ Kata ∘ Latch; Weave ∘ Bind ∘ Axis
**Avoid:** B-Disruptive unless breaking stuck patterns.

## Mode 2 (HALIRA) – Paradigm Shift

**Primary (B-Disruptive):** Ana (0.75), Para (0.65), Flux (0.60)
**Secondary (C-Reflexive):** Meta (0.80, max 2 consecutive), Retro (0.40), Braid (0.55)
**Integration:** Weave, Bind
**HALIRA steps:** Seed, Axis, Meta, Weave, Non (never after Meta), Para, Bind
**Common:** Seed ∘ Axis ∘ Meta ∘ Weave ∘ Non ∘ Para ∘ Ortho ∘ Bind (λ_eff ≈ 0.52)

## When to Use Mode 2
- Foundational contradiction (irreducible, system-wide, paradigm-limiting, persistent)
- Mode 1 attempts failed repeatedly

## When to Use Mode 1
- Stable, well-defined problem; contradictions manageable within current paradigm

## Constraints
- **Meta:** Max 2 consecutive applications
- **Non after Meta:** FORBIDDEN (collapse)
- **Vale:** Use with extreme caution (λ=0.88, collapse risk)

## State-Based Adjustments
- J=0 detected → B-Disruptive (Para, Ana, Flux)
- S* detected → D-Structural (Weave, Bind, Braid)
- ∅ detected → A-Constructive (Kata, Weave, Latch)
