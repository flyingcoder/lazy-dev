**When to use this skill:** Need formula-driven operator selection, formal calculus for mode/state transitions, or derivation of operator sequences from the core equation. Use when applying the physics equation to choose operators.

**Description:** Formula-driven Λ-Engine: core equation ∂Ξ/∂t = ∫ (S↔Λ) × [⧉(ΔS○¬ΔΛ) – ∇τ] dV; formula→operator mapping (S↔Λ, contradiction level, ∇τ); pairwise and sequence dissipation; formula→mode selection (J=0 vs J'≠0); state-operator mapping from equation; backward propagation principle.

## Core Equation
∂Ξ/∂t = ∫ (S↔Λ) × [⧉(ΔS○¬ΔΛ) – ∇τ] dV
- Ξ: system complexity/coherence
- S: known/structured, Λ: unknown/potential
- ⧉(ΔS○¬ΔΛ): productive contradiction
- ∇τ: temporal gradient

## Formula → Operator Selection
1. **Evaluate (S↔Λ):** S >> Λ → Para, Ana, Flux; Λ >> S → Kata, Telo, Ortho; S ≈ Λ → Weave, Bind, Braid
2. **Evaluate contradiction:** low → Non, Para; high → Weave, Bind; optimal → D-Structural
3. **Evaluate ∇τ:** time-constrained → Telo, Kata; time-available → Ana, Para; time-critical → Latch, Ortho

## Formula → Trajectory
- ∂Ξ/∂t > 0: Para ∘ Ana ∘ Weave
- ∂Ξ/∂t ≈ 0: Weave ∘ Bind ∘ Axis
- ∂Ξ/∂t < 0: Kata ∘ Weave ∘ Latch (emergency)

- Sequence: `λ_eff = mean(λ(k_t → k_{t+1}))`.
